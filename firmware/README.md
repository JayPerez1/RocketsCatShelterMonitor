# Cat Shelter Monitor Firmware

This folder contains firmware versions for the Cat Shelter Monitor project.

## Versions

### v1.1 – Current Development
Location:
firmware/CatShelterLogger_v1_1/

Features:
- BLE download support
- FRAM data logging
- RTC timestamping
- AMG8833 occupancy detection

### v1.0 – Legacy Version
Location:
firmware/CatShelterLogger_v1_0/

Earlier firmware used during early field testing.

## Hardware Platform

Board:
Adafruit nRF52840 Feather

Sensors:
- DS18B20 temperature sensors
- AMG8833 thermal array
- RTC
- FRAM
